        v

        |

        |
        +--> [Response/Quarantine]  isolate / terminate / network filter (M5)
        |
        +--> [ViruxApp]  SwiftUI menu-bar + dashboard (reads store, on-demand)

  [Sandbox]  Virtualization.framework disposable macOS guest, vsock agent (M4)
